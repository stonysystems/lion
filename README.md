# Lion

Lion is an experimental asynchronous runtime verified with [Verus](https://github.com/verus-lang/verus), aiming to offer an interface and performance similar to [Tokio](https://tokio.rs).

For the system and experiments as published in the SOSP '26 paper, see the [`SOSP26AE`](https://github.com/stonysystems/lion/tree/SOSP26AE) branch. This branch is for the next phase of development and exploration.
